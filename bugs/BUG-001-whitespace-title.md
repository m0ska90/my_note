# BUG-001: Сохранение заметки из пустого текста

| Поле | Значение |
|------|----------|
| **ID** | BUG-001 |
| **Описание** | Приложение сохраняет заметку при отправке только пробелов |
| **Приоритет** | Low |
| **Статус** | Open |
| **Ссылка** | TC-MSG-006 |

## Описание

При отправке сообщения, состоящего только из пробельных символов (`"   "`), бот сохраняет заметку. Это некорректное поведение — пустой контент не должен сохранять заметку.

## Шаги для воспроизведения

1. Запустить бота: `python bot_receiver.py`
2. Отправить боту сообщение: `"   "` (только пробелы)
3. Подождать 5 секунд

## Фактический результат

- В БД создана новая запись в таблице `notes`
- В поле `title`: `Заметка из MAX:    \n\n   ...` (содержит пробелы)
- В поле `description`: `"   "`

## Ожидаемый результат

- Заметка **не** создаётся
- Бот может ответить: `Сообщение пустое, заметка не создана`

## Обоснование

Пользователь не должен создавать заметки с пустым содержанием. Это создаёт мусор в базе данных.

## Предложение по исправлению

В функцию `_process_update` добавить проверку перед созданием заметки:

```python
if isinstance(text, str) and text.strip():  # Проверка strip()
    note_id = add_text_note(text)
```
