# Предположения и ограничения

## Лимиты платформы MAX
- Максимальная длина ответа бота: 4000 символов.
- Лимит API: 30 запросов/сек.
- Лимит изображений: до 50 МБ, 7680×7680px.
- Лимит видео: до 250 МБ.

## Технические детали реализации
- Токен хранится в шифрованном виде (DPAPI).
- Файлы скачиваются в `%APPDATA%\Заказики\inbox\`.
- Определение типа файла происходит по Magic Bytes (первым 16 байтам).
- База данных SQLite с journal_mode=WAL.
