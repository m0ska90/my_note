# 📓 Заметки и MAX — QA Артефакты

Полный набор тест-документации для бота-собирателя заметок в мессенджере MAX.

## 📂 Структура проекта

- `docs/assumptions.md` — предположения и ограничения (лимиты MAX API, размеры файлов).
- `docs/coverage.md` — матрица покрытия (какие функции проверены).
- `test-cases/` — сами тест-кейсы, разбитые по модулям.

## 🚀 Тест-кейсы

Все кейсы используют единый формат:
- **Приоритет** — важность тестирования.
- **Статус** — `Not run`, `Pass`, `Fail`.
- **Предусловия** — состояние системы до теста.
- **Шаги** — последовательность действий.
- **Ожидаемый результат** — проверка корректности.

## 🐛 Баги

Файлы о найденных дефектах (если обнаружены в процессе тестирования).
