📝 Заказики и MAX
Десктопное приложение для управления заметками с интеграцией мессенджера MAX. Приложение позволяет создавать события-напоминания, сохранять текстовые сообщения и вложения из бота MAX, и управлять ими в удобном интерфейсе.

🚀 Быстрый старт
Установка
pip install -r requirements.txt
Запуск
python main.py          # Основное приложение
python bot_receiver.py     # Бот-получатель сообщений из MAX
или используйте готовые скрипты:

Windows: run.bat
Linux/Mac: run.sh
📦 Требования
Python 3.10+
Windows (для DPAPI шифрования)
Доступ к API MAX Messenger
🔧 Установки компонентов
Компонент	Описание
customtkinter	Современный UI с тёмной/светлой темой
Pillow	Обработка изображений
pystray	Иконка в системном трее
requests	HTTP-запросы к MAX API
pysqlcipher3	Шифрование базы данных (опционально)
Примечание: Для полного шифрования БД установите Microsoft C++ Build Tools и выполните pip install pysqlcipher3. Без него база работает в обычном режиме.

⚙️ Конфигурация
config.json
{
  "api": {
    "base_url": "https://platform-api2.max.ru",
    "rate_limit_rps": 30,
    "long_poll_timeout": 30,
    "max_message_length": 4000
  },
  "database": {
    "journal_mode": "WAL",
    "busy_timeout_ms": 10000
  },
  "bot": {
    "allowed_chat_ids": []  // Вайтлист chat_id (пусто = принимать от всех)
  },
  "health_check": {
    "enabled": false,
    "host": "127.0.0.1",
    "port": 8080
  }
}
Переменные окружения (.env.example)
MAX_BOT_TOKEN=your_token_here
MAX_ROOT_CA_PATH=/path/to/certificate.pem
LOG_LEVEL=INFO
HEALTH_PORT=8080
Настройка токена бота
python bot_receiver.py --configure-token
Токен шифруется через DPAPI и сохраняется в %APPDATA%\Заказики\max_bot_token.dpapi

🔐 Шифрование базы данных
Приложение поддерживает два режима работы с БД:

Режим 1: Без шифрования (по умолчанию)
База данных хранится в открытом виде
Подходит для тестирования и разработки
Режим 2: С шифрованием SQLCipher
Установите Microsoft C++ Build Tools
Установите библиотеку: pip install pysqlcipher3
Перезапустите приложение
При первом запуске будет запрошен пароль для шифрования БД
Пароль хранится в зашифрованном виде через DPAPI
Миграция: Существующая нешифрованная БД автоматически мигрирует в зашифрованную с созданием резервной копии notes.db.plaintext.backup.

📊 База данных
Движок: SQLite (или SQLCipher при наличии)
Расположение: %APPDATA%\Заказики\notes.db
Таблицы:
notes — заметки и события
attachments — вложения (файлы)
Индексы:
idx_notes_remind_at — для сортировки и напоминаний
idx_notes_title — для фильтрации заметок MAX
idx_attachments_note_id — для JOIN операций
Режим журналирования: WAL (Write-Ahead Logging)

🐛 Известные проблемы и решения
pysqlcipher3 не устанавливается
Требуется Microsoft C++ Build Tools. Альтернатива — работать без шифрования БД.

Токен не сохраняется
Убедитесь, что папка %APPDATA%\Заказики существует и доступна для записи.

Вложения не скачиваются
Проверьте доступ к platform-api2.max.ru и наличие CA-сертификата.
